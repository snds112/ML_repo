# Machine Learning – Cours et Travaux Pratiques

Ce dépôt regroupe les supports de cours du module **Machine Learning** ainsi que mon travail personnel (TP et ressources complémentaires).

## 📚 Contenu

### `lecture/` — Supports de cours

Cours théoriques couvrant les fondamentaux du Machine Learning :

- Introduction
- Régression
- Régression logistique
- Arbres de décision
- Classification Naive Bayes
- Classification KNN
- Machines à vecteurs de support (SVM)
- Clustering
- Ensemble Learning

### `work/` — Travaux pratiques

Dossiers `tp1` à `tp7` contenant mon travail personnel.

> ⚠️ **À noter :** les numéros des dossiers TP ne correspondent pas forcément aux numéros des cours. Certains cours ont été traités en un seul TP, et l'ordre ne suit pas nécessairement celui des supports théoriques.

### `extra/` — Ressources complémentaires

Documents téléchargés en ligne pour approfondir certaines notions (ex. : notes sur les SVM, arbres de décision pour la régression). Ce ne sont pas des travaux personnels.
